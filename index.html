Which Mac do you have? Click → About This Mac. If it says Apple M1/M2/M3, take the first download; if it says Intel, take the second. The wrong one won't open (“not supported on this Mac”).
Installed from a .zip previously? Windows marks everything it extracts from a download as untrusted, and then refuses to load the app's own files — so a zip copy can fail to start with an error about clr or Python.Runtime.dll. The installer above doesn't mark anything, so installing over it fixes this. To rescue an existing zip copy instead, open PowerShell in that folder and run Get-ChildItem -Recurse . | Unblock-File.
Don't have a license key? The app still runs without one — motion detection, event clips and review all work. The key only enables the AI descriptions. Contact us to get one.
Updating. The app checks for new versions and shows a banner when one is available. Click Download update, install it over the old version, and your cases, footage and settings are kept — they live outside the app.
